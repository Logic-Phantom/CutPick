## 공유 동작
- `expo-sharing.shareAsync`는 **파일 1개 URL만** 받는다(SDK 58 문서 확인). 여러 장 동시 공유를 약속하지 않고, "번호 붙여 사진 앱에 저장 → 목적 앱에서 순서대로 선택"을 기본 경로로 안내.
- 목적 앱별 공유 시트 동작은 **실기기 미검증**.
- 자동 게시·비공식 API·자동 로그인은 구현하지 않음.
