# 테스트

## 실행 명령
```bash
npm test            # jest (unit + integration)
npm run typecheck   # tsc --noEmit
npx eslint .        # 린트 (npm run lint 은 expo lint)
npm run bench       # 데스크톱 Node 분석 코어 벤치마크 (기기 측정 아님)
```
