# 핵심 UX 흐름

## 사용자와 목표
| 사용자 | 목표 |
|---|---|
| 여행 후 수십~수백 장을 가진 사람 | 중복을 걸러 6~10장 캐러셀을 빨리 만든다 |
| 카페·음식·데이트 사진을 올리는 사람 | 밝고 선명한 대표 컷을 고르고 캡션까지 끝낸다 |
| 카카오톡 프사·배경을 바꾸려는 사람 | 후보 3장을 비교해 하나를 고른다 |
| 원본을 외부에 올리기 싫은 사람 | 기기 안에서만 처리되는지 확인할 수 있어야 한다 |

## 흐름 (탭 수 최소화)
1. **첫 실행** → 취향 마법사 6단계(D-029): **① 사진 취향**(실제 사진 16장 중 마음에 드는 것 3~8개, 카테고리 전체/분위기/구도/색감·빛/장면, 카테고리를 바꿔도 선택 유지, 3개 미만이면 이유를 보여 주며 "계속하기" 비활성, 8개 초과 탭은 무시하고 안내) → ② 음식 각도 → ③ 인물·OOTD 구도 → ④ 보정 → ⑤ 올릴 곳 → ⑥ 개인정보 요약. 상단 "건너뛰기"(첫 실행만, 전체), 하단 "넘기기"(그 단계의 저장 안 된 변경은 버리고 다음으로), 상단 "이전 단계". 단계마다 저장, 완료·건너뛰기 후에는 다시 강제하지 않음. 예전의 피사체·색감·구도 칩은 ①의 해당 카테고리 아래 "사진에 없는 세부 취향 고르기"로 남아 있음.
2. **탭 4개(D-051)** → **홈**: 오늘의 픽 배너·베스트샷 샘플 둘러보기(카테고리 필터) + "내 사진으로 베스트샷 찾기/이어서 하기" 한 줄 카드. **사진 추천**: 1-2-3 흐름 설명 + "새 프로젝트 시작" + 이어서 하기 + 프로젝트 목록 + 취향 안내. **커뮤니티**: 실제 게시물 + 베스트샷 샘플. **내 정보**: 로컬 통계·취향·내 프로젝트, 톱니 → 설정.
3. **새 프로젝트** → 이름·유형·(선택)촬영시간 사용 → "사진 선택"(OS 선택기) → 선택 장수·제외 사유 확인 → "N장으로 추천 받기"(헤더에 1-2-3 단계 표시, 하단 "이전"). 사진이 없으면 "샘플 사진으로 체험".
4. **분석** → 실제 단계·처리 수·실패 수, 썸네일이 들어오는 대로 표시, 멈추기/이어서/실패만 재시도, 분석 범위(지원/미지원) 표시 → "추천 보기".
5. **추천 결과** → 대표 사진 히어로(추천 이유 + 측정값 4개) → 요약(플랫폼·목적·비율·프리셋) + 목표 장수 스테퍼(`선택/목표`) → 큰 타일 묶음(크롭 미리보기, 순번, 고정·그룹 배지, 대표 이유 1줄) → 탭 시 시트(전체 이유, 앞/뒤/첫 장, 고정, 묶음에서 빼기, 그룹 대표 교체, 상세). 여러 장을 연달아 옮길 때는 "순서 바꾸기" → 타일별 ←/→ 버튼 → "완료". 스크린 리더는 타일의 동작 메뉴(앞으로 옮기기/뒤로 옮기기/첫 장으로)로 바로 옮길 수 있고, 어느 경로든 "N번째로 옮겼어요"를 읽어 준다(D-044) → 다른 후보/제외한 사진 → 하단: 되돌리기 · 다시 추천 · 저장·공유하기.
6. **저장·공유** → 게시 순서 미리보기(크롭 위치 앞/가운데/뒤), 캡션 편집·복사(성공/실패 표시), 공유 안내 → "순번대로 사진 앱에 저장"(주 CTA) 또는 파일별 공유 → (선택) 커뮤니티 공개.
7. **커뮤니티** → 피드(카테고리), 게시물(하트·신고·차단), 내 게시물, 계정.

## 상태별 화면
| 상태 | 처리 |
|---|---|
| 프로젝트 없음 | 홈 EmptyState + CTA |
| 선택 전 | 선택 범위·권장/최대 장수·로컬 처리 안내 |
| 분석 중 / 일부 실패 / 취소 | ProgressPanel, 경고 메시지, 재시도 |
| 많은 사진 | 150장 초과 시 경고, 300장 초과분 제외 표시 |
| 결과 없음 | 원인(모두 제외 / 미분석)과 해결 버튼 |
| 저장·공유 오류 | 오류 안내 + 한 장씩 공유 대체 경로 |
| 권한 거부 | 설정에서 바꾸는 방법 안내 |
| 모델 미설치 | 해당 없음(모델 미사용) — 분석 범위에 미지원 표시 |
| 커뮤니티 미설정 / 미로그인 / 백엔드 오류 | 각각 별도 EmptyState·메시지, 로컬 기능 유지 |

## 취향 관리
- 설정 → 내 취향: 고른 사진 썸네일·요약, "취향 수정"(첫 실행과 같은 마법사, 저장한 선택이 미리 체크됨), "초기화"(확인 시트 → 카드·태그·답변 삭제, 개인화 스위치·학습 기록은 유지).
- 추천 결과 요약 카드의 "내 취향 반영 · …"을 탭해도 취향 수정으로 이동.
- 취향이 없으면(건너뛰기·초기화) 추천은 기술 신호·프리셋·목적 적합도만으로 이전과 같이 동작하고 이유에 "취향"을 언급하지 않음.

## 상태 보존
- 분석 상태는 사진별로 DB에 저장 → 앱 재시작 후 "이어서 분석".
- 추천 편집(고정·제외·순서·대표·캡션·크롭)은 변경 즉시 저장, 목적별로 따로 보존.
- 사진 상세에서 돌아와도 추천 화면 상태 유지(스택 위 모달).
