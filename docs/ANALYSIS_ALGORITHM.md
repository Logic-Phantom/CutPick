# 분석 알고리즘 (analysisVersion 2)

모든 상수는 `src/domain/recommendation-policy.ts`에 있다. 수치는 조정 가능한 출발점이며 객관적 미적 기준이 아니다.

## 1. 입력 준비
- 원본 → `expo-image-manipulator`로 긴 변 480px 썸네일(JPEG q0.8, 앱 저장소) → 다시 긴 변 128px JPEG(q0.92, base64) → `jpeg-js`로 RGBA 디코드.
- 원본 해상도 이미지를 JS 메모리에 올리지 않는다. 동시성 2.
- EXIF 회전/HEIC 디코드는 네이티브 디코더에 의존 (**실기기 미검증**).

## 2. 기술적 품질 신호 (pixel-metrics.ts)
| 신호 | 계산 | 비고 |
|---|---|---|
| 선명도 | 휘도(Rec.601) 4-이웃 라플라시안 분산 → `sqrt(var/900)` 0..1 | 128px 기준. **한계: 강한 노이즈/그레인은 디테일로 읽혀 선명도가 올라갈 수 있음** |
| 노출 | `1 − 0.7·|평균−128|/128 − 1.5·(하이라이트 ≥250 비율 + 섀도 ≤6 비율)` | 어두운 연출 사진은 프리셋의 exposureWeight로 감점 완화 |
| 대비 | 휘도 표준편차/64 | |
| 해상도 | 원본 MP / 8MP | |
| 색 통계 | Hasler–Süsstrunk colorfulness/100, warmth=(R−B)/80, 평균 RGB | 취향 매칭과 중복 판정 보조 |

기술 점수 `technicalQuality = (0.4·선명 + 0.3·노출·w + 0.15·대비 + 0.15·해상도)/정규화` — 취향과 분리된 피처로 저장한다.

## 3. 유사 사진 그룹 (D-008)
- 서명: 128px 이미지를 16×16 면적평균 휘도로 축소(512 hex).
- 거리: 각 서명에서 평균을 뺀 뒤 평균 절대차(밝기 불변). 캐시 + 조기 종료.
- 조건: 거리 ≤ **5** AND 평균색 거리 ≤ 40 AND (두 사진 모두 촬영시각이 있으면) 600초 이내. union-find로 묶고 기술 점수 최고를 기본 대표로.
- 보정 근거(샘플 18장, `tests/integration/sample-images.test.ts`): 실제 중복(이동·흐림·밝기 변경) 거리 0.6–2.2, 무관 사진 최소 10.0. dHash는 같은 쌍에서 해밍 18–31로 분리 실패 → 폐기.
- **실사진 미검증**: 연사·표정 변화 사진에서의 임계값은 실제 사진·사용자 평가로 재조정 필요.

## 4. 추천 점수 (scoring.ts)
```
total = quality·presetQualityWeight
      + 0.35·(취향일치 − 0.5)·2        # 밝기/채도/색온도 목표와의 유사도 (목표 없으면 0)
      + 0.20·tanh(학습가중치·피처/2)·warmup   # 개인화 켜짐일 때만
      + 0.35·크롭보존율                # 목표 비율로 가운데 크롭 시 남는 면적
      + 그룹 대표 +0.10 / 비대표 −0.60
```
- 취향 목표 = 온보딩 색감 선택(평균) 60% + 프리셋 목표 40%.
- 분석 안 된 사진은 품질·취향 0 → 후보 하단.

## 5. 선택과 순서
- `selectDiverse`: 고정 사진 먼저 → 그룹 비대표를 뺀 후보에서 `점수 − 0.35·최대유사도 + 방향 0.05 + 장면태그 0.08`로 탐욕 선택 → 부족하면 그룹 비대표에서 보충(이유에 표시). 제외 사진은 절대 선택하지 않음.
- 유사도 = `max(0, 1 − 서명거리/25)`.
- 순서: 첫 장 = 최고점(고정 우선). 나머지 60% 이상이 촬영시각 보유 → 시간순, 아니면 직전 사진과 유사도가 낮은 순서. 사용자가 순서를 바꾸면 그 순서를 유지하고 새 사진만 뒤에 붙임.
- 단일 목적(프사·배경·단일 게시물)은 대표 후보 3장을 비교로 제시.

## 6. 설명 (explanations.ts)
실제 계산된 신호만 문장으로 만든다(테스트로 얼굴/눈/표정/외모 단어 미포함 확인). 예: "선명하고 노출이 안정적이에요", "세로 4:5로 자르면 화면의 32%가 잘려요", "비슷한 연속 사진 중 대표 후보예요".

## 7. 미지원 (UI 표기)
장면 분류(수동 태그), 얼굴 감지, 눈 감김, 표정, 미적 점수 — `HEURISTIC_CAPABILITIES`에 명시, 분석 화면·설정에 그대로 표시.
