# 트렌드 조사와 프리셋 검수 절차

## 현재 상태 (2026-10-18)
- 7개 프리셋(자연스러운 일상, 여행 기록·포토덤프, 카페·음식, 레트로 디카·직광 플래시, 차분한 필름·낮은 채도, 야간·네온, 따뜻한 가족·기념일)은 **모두 가설**이다: `status: experimental`, `confidence: hypothesis`, `sources: []`.
- 프리셋은 추천 순위만 조정하고 사진에 색 보정을 적용하지 않는다(`appliesColorFilter: false`).
- 앱은 실시간 트렌드를 분석한다고 표시하지 않는다. 캡션 해시태그도 고정 목록이다.

## 원칙
- 비공개·로그인 전용 데이터 스크래핑, 약관 위반 수집기 금지.
- 하나의 바이럴 게시물·해시태그로 한국 사용자 전체 취향을 일반화하지 않는다.
- 유명 사진가·상용 필터 팩·브랜드 이름/색값을 복제하지 않는다. 일반 스타일 명칭 + 자체 파라미터.

## 검수 절차 (사람이 수행, 최소 120일마다)
1. 공개 출처 수집: 플랫폼 공식 트렌드 리포트(예: Instagram/TikTok 공식 뉴스룸·크리에이터 자료), 공개된 사진/패션 트렌드 보고서. URL·제목·확인일 기록.
2. 프리셋별로 근거 매핑: 근거가 2개 이상 독립 출처면 `confidence: medium`, 공식 리포트 포함 시 `curated` 후보.
3. `presets.ts` 수정: `sources[]`(https URL·checkedAt), `lastReviewedAt`, `status`, `notes`.
4. `npm test` 실행 — `validatePresets()`가 다음을 강제: curated는 출처 필수, 출처 없는 프리셋은 hypothesis, 날짜·범위 유효성.
5. 근거가 사라진 프리셋은 `retired`(앱에서 숨김, 기존 프로젝트는 기본 프리셋으로 대체).
6. 120일 이상 미검토 프리셋은 UI에 "(검토 필요)"가 자동 표시된다(`isPresetStale`).

## 원격 업데이트
초기에는 앱 번들에 포함된 로컬 목록만 사용. 원격 갱신을 추가하려면 호스팅 약관·한도, 서명/버전 검증, 롤백 경로를 먼저 정한다.
