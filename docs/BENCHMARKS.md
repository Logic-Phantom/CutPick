# 벤치마킹 (경쟁/참고 앱 UX)

확인일: 2026-10-18

이번 작업에서는 외부 앱을 설치·역분석하지 않았다(REA 미사용, D-024). 공개적으로 널리 알려진 일반 UX 패턴만 추상 수준에서 참고했고, 코드·문구·아이콘·에셋은 복제하지 않았다.

| 일반 패턴 | 컷픽에서 독립적으로 다르게 설계한 점 |
|---|---|
| OS 사진 선택기로 다중 선택 | 라이브러리 전체 접근 권한을 요구하지 않음. 선택 장수·제외 사유(영상/형식/상한)를 즉시 표시 |
| 갤러리 그리드에서 선택 표시 | 색상만이 아닌 체크/번호/핀/눈가림 아이콘 배지로 상태 표현 |
| 피드의 하트 반응 | 하트 수만 표시, 순위·인기순 정렬 없음, 댓글/DM 없음 |
| 캐러셀 순서 편집(드래그) | 드래그 대신 "앞으로/뒤로/첫 장으로" 버튼 — 접근성 대체 수단 |

후속: 실제 벤치마킹이 필요하면 공개 화면 관찰 기록(출처·날짜)을 이 문서에 추가한다.
