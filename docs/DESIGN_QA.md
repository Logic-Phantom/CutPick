## 남은 문제 / 관찰
- 웹에서 가로(1080×720) 샘플을 4:5로 내보낸 결과가 640×800으로 기대값과 다름 — **Android 실기기에서는 정확**(405×720 등)해 웹 manipulator 차이로 판단.
- 이미지가 페이드 인 중 캡처되면 흐리게 보임(전환 120ms) — 기능 문제 아님.
- 강한 그레인 사진을 "흔들림이 적고 선명"으로 설명하는 경우가 있음(라플라시안 한계, ANALYSIS_ALGORITHM 참고).
- 카테고리 태그를 비활성 FilterChip으로 표시해 스크린리더가 "체크박스, 사용 안 함"으로 읽을 수 있음 → 전용 Tag 컴포넌트 필요(ROADMAP).
