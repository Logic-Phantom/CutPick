## 자세한 설명 (2026-10-24 소유자 확정)
CutPick - 나만의 베스트샷을 찾아보세요 ✨
수많은 사진 중 어떤 사진을 올릴지 고민되시나요?

CutPick은 나만의 사진 취향을 설정하고, 촬영한 사진을 분석해 SNS에 올리기 좋은 사진을 선택할 수 있도록 도와주는 사진 추천 앱입니다.
📸 나에게 어울리는 베스트샷 찾기
여행, 카페, 음식, 인물, 일상까지 다양한 사진을 살펴보세요. 여러 장의 사진 중 마음에 드는 사진을 찾고, 나만의 취향에 맞는 사진을 선택하는 데 도움을 받을 수 있습니다.
🎨 나만의 사진 취향 설정
내가 좋아하는 사진 스타일을 선택해 보세요. 취향에 맞는 예시를 살펴보고, 어떤 사진을 선호하는지 직접 설정할 수 있습니다.
🖼️ 다양한 사진을 한곳에서
여행지의 풍경, 카페의 감성적인 순간, 맛있는 음식, 일상의 소소한 장면까지. 다양한 사진을 탐색하며 새로운 촬영 아이디어를 발견해 보세요.
💗 마음에 드는 사진을 저장하고 공유하기
추천 결과를 확인하고 마음에 드는 사진을 저장하거나 공유해 보세요. 커뮤니티에서는 다른 사람들이 공유한 사진을 둘러보고, 마음에 드는 사진에 하트를 남길 수 있습니다.
🔒 내 사진은 내 기기에서
CutPick의 주요 사진 분석 및 추천 기능은 기기 내 처리를 중심으로 설계되었습니다. 원본 사진을 자동으로 업로드하거나 외부 SNS에 자동으로 게시하지 않습니다. 커뮤니티에 사진을 공유할 때는 사용자가 직접 공유를 선택합니다.
✨ 오늘의 순간을 더 특별하게
- 내 사진에서 베스트샷 찾기
- 나만의 사진 취향 설정하기
- 다양한 주제의 사진 탐색하기
- 마음에 드는 사진 저장하고 공유하기
- 커뮤니티에서 새로운 사진 영감 얻기
좋은 사진은, 함께 볼 때 더 빛나니까.
