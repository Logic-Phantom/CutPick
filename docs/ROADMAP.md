# 로드맵

## 완료 (코드 + 단위/통합 테스트 + 웹 미리보기)
- Phase 1: 디자인 시스템, 온보딩, 프로젝트 CRUD, 사진 선택, SQLite·파일 저장, 샘플 모드
- Phase 2: 픽셀 품질 지표, 휘도 서명 중복 그룹, 분석 큐(진행·취소·재시도·재개), 추천 엔진·설명
- Phase 3: 플랫폼 목적·비율·장수, 크롭 미리보기·위치 조정, 캡션 템플릿·복사, 순번 내보내기
- Phase 4(코드): Supabase 스키마·RLS·트리거·RPC, 게시 동의·피드·하트·신고·차단·내 게시물·계정 삭제

3. 출시 전 필수: 지원 이메일 설정, 정책 문서 법률 검토, 자체 앱 아이콘, 앱 내 오픈소스 라이선스 화면, 연령 정책, 상표 조사, 의존성 라이선스 자동 감사.
